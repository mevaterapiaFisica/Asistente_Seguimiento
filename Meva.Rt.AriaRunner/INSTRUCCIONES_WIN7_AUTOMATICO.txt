================================================================
  Meva.Rt AriaRunner - Win7 + Automatizacion Task Scheduler
================================================================

INDICE
  1. Descripcion del flujo automatizado
  2. Requisitos
  3. Compilar el ejecutable net48 (desde Win10)
  4. Copiar archivos a la PC con ARIA (Win7)
  5. Compartir la carpeta de datos en Win10
  6. Configurar Task Scheduler en Win7
  7. Configurar Task Scheduler en Win10
  8. Verificacion manual antes de activar las tareas
  9. Solucion de problemas


================================================================
  1. DESCRIPCION DEL FLUJO AUTOMATIZADO
================================================================

  Win10 Tarea 1 (ej. 07:00)
    aria-export-ids.bat
    Llama al web server local → scrape SitraMed para obtener IDs
    Guarda: C:\...\Meva.Rt.Web\data\pacientes.json
    (misma carpeta compartida en red como \\WIN10\MevaRtData)

  Win7 Tarea (ej. 07:10)
    win7-aria-query.bat
    AriaRunner.exe lee  \\WIN10\MevaRtData\pacientes.json
    Consulta la BD de ARIA
    Escribe \\WIN10\MevaRtData\aria_results_TIMESTAMP.json

  Win10 Tarea 2 (ej. 07:45)
    refresh.bat  (ya existente, sin cambios)
    Importa aria_results_*.json del dir data\
    Refresca el dashboard completo


================================================================
  2. REQUISITOS
================================================================

  PC con ARIA (Win7 SP1):
  - .NET Framework 4.8
    Descargar: https://dotnet.microsoft.com/download/dotnet-framework/net48
    O buscar "ndp48-web.exe" en el sitio de Microsoft.
    (Win7 SP1 + las actualizaciones de seguridad minimas son suficientes)
  - Acceso de red a la BD de ARIA (SQL Server, usualmente integrado)
  - Acceso de red a la carpeta compartida del Win10

  PC principal (Win10):
  - El web server MevaRT corriendo (puerto 5062)
  - curl.exe disponible (incluido en Windows 10 desde version 1803)
  - La carpeta data\ compartida en red (ver Paso 5)


================================================================
  3. COMPILAR EL EJECUTABLE net48 (desde Win10)
================================================================

  Desde cmd o PowerShell, en la carpeta del proyecto:

    cd C:\Pablo\WebScrapSitra\Meva.Rt\Meva.Rt.AriaRunner

  Compilar para .NET Framework 4.8:

    dotnet publish -f net48 -c Release -o publish\net48

  Esto genera la carpeta:
    Meva.Rt.AriaRunner\publish\net48\

  Contenido relevante de esa carpeta:
    AriaRunner.exe            <- ejecutable principal
    AriaRunner.exe.config     <- config de conexion (editar si hace falta)
    EntityFramework.dll
    EntityFramework.SqlServer.dll
    Newtonsoft.Json.dll
    AriaQ.dll                 <- debe aparecer aca (copiada automaticamente)

  NOTA: Si AriaQ.dll no aparece, copiarla manualmente desde:
    C:\Pablo\WebScrapSitra\Insumos ARIA\AriaQ.dll

  NOTA SOBRE ARQUITECTURA (32 vs 64 bits):
  Si AriaQ.dll es 32-bit y AriaRunner falla con error de arquitectura,
  compilar con plataforma x86:
    dotnet publish -f net48 -c Release -o publish\net48 -p:PlatformTarget=x86


================================================================
  4. COPIAR ARCHIVOS A LA PC CON ARIA (Win7)
================================================================

  Crear la carpeta C:\AriaRunner en la PC con Win7 (o donde prefieras).

  Copiar el contenido COMPLETO de publish\net48\ a esa carpeta:
    AriaRunner.exe
    AriaRunner.exe.config
    EntityFramework.dll
    EntityFramework.SqlServer.dll
    Newtonsoft.Json.dll
    AriaQ.dll

  VERIFICAR QUE AriaRunner.exe.config TENGA LA CONNECTION STRING CORRECTA:

    El archivo se ve asi:
    <connectionStrings>
      <add name="variansystemEntities"
           connectionString="metadata=res://*/Aria.csdl|...;
                             data source=ARIAMEVADB-SVR;
                             initial catalog=variansystem;
                             integrated security=True;..."
           providerName="System.Data.EntityClient" />
    </connectionStrings>

    Verificar que "data source" apunte al servidor SQL correcto.
    Si necesitas ajustarlo, editar directamente ese archivo con
    el Bloc de notas antes de copiar.

  NOTA: No necesitas instalar nada mas en Win7 ademas de .NET 4.8.
  No se necesita Visual Studio ni el SDK de .NET.


================================================================
  5. COMPARTIR LA CARPETA DE DATOS EN WIN10
================================================================

  La carpeta que se comparte es la de datos del web server:
    C:\Pablo\WebScrapSitra\Meva.Rt\Meva.Rt.Web\data

  Pasos para compartirla:
  1. Click derecho sobre la carpeta "data" → Propiedades
  2. Pestana "Compartir" → "Uso compartido avanzado"
  3. Tildar "Compartir esta carpeta"
  4. Nombre del recurso: MevaRtData
  5. Permisos: agregar la cuenta con la que corre la tarea en Win7
     (usualmente "Todos" o la cuenta de dominio del operador)
     Permisos: Lectura y Escritura (necesita escribir los resultados)
  6. Aceptar

  La ruta UNC quedara como:
    \\NOMBRE-DEL-WIN10\MevaRtData

  Reemplazar NOMBRE-DEL-WIN10 por el nombre real del equipo Win10.
  Para verlo: click derecho en "Mi PC" → Propiedades → Nombre de equipo.

  PRUEBA RAPIDA desde Win7:
  Abrir el Explorador de Windows y escribir en la barra de direccion:
    \\NOMBRE-DEL-WIN10\MevaRtData
  Debe mostrar el contenido de la carpeta data\.


================================================================
  6. CONFIGURAR TASK SCHEDULER EN WIN7
================================================================

  Script a ejecutar: win7-aria-query.bat
  (copiar este archivo a la PC Win7, ej. C:\AriaRunner\win7-aria-query.bat)

  ANTES de crear la tarea, editar win7-aria-query.bat y cambiar:
    set WIN10_SHARE=\\WIN10-HOSTNAME\MevaRtData
      → reemplazar WIN10-HOSTNAME por el nombre real del equipo Win10
    set RUNNER_DIR=C:\AriaRunner
      → ruta donde esta AriaRunner.exe

  CREAR LA TAREA EN TASK SCHEDULER:
  1. Inicio → Programas → Accesorios → Herramientas del sistema
     → Programador de tareas
  2. "Crear tarea basica" (panel derecho)
  3. Nombre: Meva RT - Consulta ARIA
  4. Desencadenador: Diariamente
     Hora de inicio: 07:10 (10 minutos despues de la tarea de exportacion)
     Repetir cada: 4 horas (opciones avanzadas)
     Durante: 1 dia
  5. Accion: Iniciar un programa
     Programa: C:\AriaRunner\win7-aria-query.bat
     (o: cmd /c "C:\AriaRunner\win7-aria-query.bat")
     Iniciar en: C:\AriaRunner
  6. Configuracion:
     - Tildar "Ejecutar tanto si el usuario inicio sesion como si no"
     - Tildar "Ejecutar con los privilegios mas altos" (si la BD lo requiere)
     - En "Configurar para": Windows 7
  7. Finalizar y guardar (puede pedir contrasena de la cuenta)

  REPETICION CADA 4 HORAS:
  En la pestana Desencadenadores → Editar desencadenador:
  - Tildar "Repetir tarea cada:" → seleccionar "4 horas"
  - Durar: "1 dia"
  Esto ejecutara la tarea a las: 07:10, 11:10, 15:10, 19:10


================================================================
  7. CONFIGURAR TASK SCHEDULER EN WIN10
================================================================

  --- TAREA 1: Exportar IDs (NUEVA) ---

  Script: scripts\aria-export-ids.bat
  Nombre: Meva RT - Exportar IDs para ARIA
  Hora:   07:00 (10 minutos ANTES que la tarea Win7)
  Repetir cada 4 horas (07:00, 11:00, 15:00, 19:00)

  Como crear la tarea:
  1. Inicio → Buscar → Programador de tareas
  2. "Crear tarea" (no "basica", para tener mas opciones)
  3. General:
     - Nombre: Meva RT - Exportar IDs para ARIA
     - "Ejecutar tanto si el usuario inicio sesion como si no"
  4. Desencadenadores → Nuevo:
     - Diariamente, 07:00
     - Repetir cada 4 horas durante 1 dia
  5. Acciones → Nuevo:
     - Programa: cmd.exe
     - Argumentos: /c "C:\Pablo\WebScrapSitra\Meva.Rt\scripts\aria-export-ids.bat"
     - Iniciar en: C:\Pablo\WebScrapSitra\Meva.Rt\scripts
  6. Condiciones: deseleccionar "Iniciar solo si el equipo esta conectado a CA"
  7. Aceptar

  --- TAREA 2: Refresh completo (YA EXISTE) ---

  Script: scripts\refresh.bat
  Hora:   07:45 (despues de que Win7 termino; la tarea ya deberia existir)
  Si no existe, crearla igual que Tarea 1 pero con refresh.bat y 07:45.

  El refresh.bat ya incluye:
  - Importar aria_results_*.json del dir data\    (Paso 1)
  - Scrape SitraMed + actualizar dashboard        (Paso 2)
  - Scrape agenda equipos                         (Paso 3)
  - Scrape agenda tomografos                      (Paso 4)

  HORARIOS SUGERIDOS (todos con repeticion cada 4 horas):
    07:00 → aria-export-ids.bat   (Win10, exporta IDs)
    07:10 → win7-aria-query.bat   (Win7,  consulta ARIA)
    07:45 → refresh.bat           (Win10, importa + refresca)


================================================================
  8. VERIFICACION MANUAL ANTES DE ACTIVAR LAS TAREAS
================================================================

  Paso A: Probar la exportacion de IDs (en Win10)
  --------------------------------------------------
  1. Asegurarse de que el servidor MevaRT este corriendo
  2. Abrir cmd y ejecutar:
       cd C:\Pablo\WebScrapSitra\Meva.Rt\scripts
       aria-export-ids.bat
  3. Verificar que se crea el archivo:
       C:\Pablo\WebScrapSitra\Meva.Rt\Meva.Rt.Web\data\pacientes.json
  4. Abrir el archivo y confirmar que tiene el formato correcto:
       { "patientIds": ["1-117505-0", ...], "count": N }

  Paso B: Probar AriaRunner desde Win7 (con la carpeta compartida)
  -----------------------------------------------------------------
  1. Desde Win7, abrir cmd y navegar a C:\AriaRunner
  2. Ejecutar:
       AriaRunner.exe --input="\\WIN10-HOSTNAME\MevaRtData\pacientes.json" --output-dir="\\WIN10-HOSTNAME\MevaRtData"
  3. Verificar en la carpeta compartida (desde Win10 o Win7) que aparece:
       data\aria_results_YYYYMMDD_HHMMSS.json
  4. El log queda local en Win7:
       C:\AriaRunner\aria_runner_YYYYMMDD_HHMMSS.log

  Paso C: Probar el refresh (en Win10)
  ------------------------------------
  1. Abrir cmd y ejecutar:
       cd C:\Pablo\WebScrapSitra\Meva.Rt\scripts
       refresh.bat
  2. Confirmar que el dashboard refleja los datos de ARIA actualizados.


================================================================
  9. SOLUCION DE PROBLEMAS
================================================================

  ERROR: AriaRunner no inicia / "This application could not be started"
  → .NET Framework 4.8 no esta instalado en Win7.
    Descargar e instalar: ndp48-web.exe o ndp48-x86-x64-allOS-enu.exe
    de https://dotnet.microsoft.com/download/dotnet-framework/net48

  ERROR: "Could not load file or assembly 'AriaQ'"
  → AriaQ.dll no esta en la misma carpeta que AriaRunner.exe.
    Copiarla desde: C:\Pablo\WebScrapSitra\Insumos ARIA\AriaQ.dll

  ERROR: "BadImageFormatException" o error de arquitectura
  → AriaQ.dll es 32-bit pero AriaRunner compilo para 64-bit.
    Recompilar con: dotnet publish -f net48 -p:PlatformTarget=x86 ...

  ERROR al leer pacientes.json desde ruta UNC:
  → Verificar que la carpeta compartida tenga permisos de Lectura
    para la cuenta con la que corre la tarea en Win7.
  → Probar manualmente desde Win7: explorador → \\WIN10\MevaRtData

  ERROR al escribir aria_results en ruta UNC:
  → La carpeta compartida necesita tambien permisos de Escritura.
  → Revisar en Win10: clic derecho en data\ → Compartir → Permisos

  ERROR de conexion a ARIA ("SqlException", "Unable to connect"):
  → Editar AriaRunner.exe.config y verificar el data source.
  → La cuenta de Windows que corre la tarea debe tener acceso a la BD.

  La tarea en Win7 termina antes de que Win10 exporte los IDs:
  → Ajustar los horarios: dar al menos 5-10 min entre la tarea Win10
    de exportacion y la tarea Win7.

  Acumulacion de archivos aria_results_*.json en la carpeta data\:
  → El endpoint import-results siempre toma el mas reciente. Los
    anteriores se pueden borrar manualmente o automatizar con un bat
    que elimine los mas viejos de N dias.
