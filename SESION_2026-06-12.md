# Sesión 2026-06-12

## Problemas resueltos

### 1. Error 500 en refresh (bug crítico)
- **Causa**: `ToDictionary()` sin `GroupBy` en la construcción de `currentById` dentro del bloque de detección de eventos de proceso. Lanzaba `ArgumentException` cuando había pacientes con PatientIds duplicados entre centros.
- **Síntoma**: El primer refresh funcionaba (previousBootstrap era null, se saltaba el bloque). A partir del segundo refresh el bloque corría y fallaba.
- **Fix**: `GroupBy(p => p.PatientId!)...ToDictionary(g => g.Key, g => g.First())` — mismo patrón ya usado para las transiciones.

### 2. Detección de suspensiones eliminada
- El usuario aclaró que no es relevante detectar "TreatmentSuspended": si un paciente desaparece del seguimiento es porque empezó tratamiento (correcto), no una suspensión.
- Se eliminó el bloque de detección y la sección "Suspensiones" de la UI de Alertas.
- Quedan activos: TechniqueChanged y StageRegressed.
