## 1. AriaRunner — paralelización (experimental, revertida)

- Se probó paralelización con 1/3/5/7/10 workers sobre 938 pacientes.
- Resultado: 1 worker=27.2 min, 10 workers=16.4 min → 1.65× speedup. No justifica complejidad.
- **Se revirtió a 1 worker secuencial** (default). El argumento `--workers=N` queda disponible.
- Logger.cs ahora es thread-safe (lock en `Write`).
- Ver `IDEA_aria_bulk_query.md` para la alternativa de mayor impacto (bulk query, estimado 5-10×).

## 3. Bug IGRT: etiqueta incorrecta

**Problema:** `TreatmentClassifier.Classify("IGRT - Prostata+...")` retornaba `"3DC"` (fallback) → `BuildLabel("3DC", "VMAT", ...)` → `"VMAT"`.

**Fix:** Una línea en `TreatmentClassifier.Classify()`:
```csharp
if (t.Contains("IGRT", StringComparison.OrdinalIgnoreCase)) return "IGRT";
```
Agregada antes del check de VMAT. Ahora `BuildLabel("IGRT", "VMAT", ...)` → `"IGRT - VMAT"`.

Los tres casos cubren:
- `"IGRT - ..."` + ARIA=VMAT → **IGRT - VMAT**
- `"IGRT - ..."` + ARIA=IMRT → **IGRT - estático**
- `"IGRT - ..."` + sin ARIA → **IGRT**

**Activar:** próximo refresh de SitraMed / apply-aria.

## 4. Tab Derivación — mejoras

### Botón "Ya atendido"
- Nuevo estado `'atendido'` en `deriv.asignaciones`.
- Botón `✓` en cada card (al lado del ⊗ suspender), toggle igual que suspender.
- Badge verde "✓ Ya atendido". En reporte HTML: fondo verde tenue, texto "Ya atendido ese día".

### Ordenamiento al fondo
- Al marcar derivado / suspendido / atendido, la lista re-renderiza con sort:
  `sin_asignar (0) → derivado (1) → suspendido (2) → atendido (3)`.

### Botones de reporte renombrados
- "Exportar HTML" → **"Generar reporte"** — deshabilitado si hay `sinAsignar > 0`.
- "Exportar igual" → **"Reporte Incompleto"** — siempre habilitado.
- Barra agrega contador **"Atendidos: N"**. Atendidos se restan del sinAsignar.

### Fecha en tarjeta (simplificada)
- **Antes:** fecha y horario mostraban la fecha dos veces ("05/06" + "🕐 05/06 07:00").
- **Ahora:** un solo día → "05/06 🕐 07:00". Múltiples días → solo "🕐 05/06 07:00 · 06/06 08:00" (sin fecha separada).

### Filtro de equipos — IGRT no mandatorio
- `_checkCompat` corregido:
  - `IGRT-VMAT` → requiere VMAT; `warn = !canDoIGRT` (antes siempre `true`).
  - `IGRT / IGRT-estático` → ok para todas; `warn = !canDoIGRT`.
- Botones rápidos: máquinas sin IGRT aparecen en naranja con ⚠ y tooltip "No hace IGRT".
- Reporte HTML: columna Observaciones muestra **"No hace IGRT"** cuando aplica.
- `_getSortedCompatMachines` ahora retorna `{ ...machine, compat }` con info de warn.
